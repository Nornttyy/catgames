# 小猫游戏多

[进入游戏](https://nornttyy.github.io/catgames/)

竖屏猫咪小游戏合集：桌子捣蛋、偷吃鱼干、小猫跳一跳、猫猫跑酷赛、猫咪大乱斗。

手机使用画面按钮或滑动；厨房大乱斗也支持 A/D 移动、空格跳跃、S 跳下、J 冲撞。
跑酷和大乱斗的对手为电脑控制。成绩保存在当前浏览器本地。

本项目为静态网站，可使用 GitHub Pages 从 main 分支根目录发布；不需要构建或后端服务器。
首次点击后播放声音，静音开关位于主菜单和暂停页。

音乐和音效的作者、许可证及修改说明见 [声音署名](audio-credits.html)。
第三方声音保留其原许可证；本仓库公开不代表其他素材另行授权。
