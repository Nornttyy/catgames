# 小猫游戏多 · Canvas

[进入游戏](https://nornttyy.github.io/catgames/)

竖屏猫咪小游戏合集：桌子捣蛋、偷吃鱼干、小猫跳一跳、猫猫跑酷赛、猫咪大乱斗。
已按用户要求恢复迁移前的 HTML / CSS / JavaScript / Canvas 2D 网页版本。首页不加载 Unity。

## 游玩

手机使用画面按钮或滑动。大乱斗支持 A/D 移动、空格/W/K 跳跃、S 跳下、J 冲撞；Esc 暂停。
跑酷是 3 只猫，大乱斗是 6 只猫；对手均为电脑控制。两种模式都可选地图和休闲、普通、困难难度。
成绩保存在当前浏览器。首次返回网页版本时合并旧网页与 Unity 的最好成绩，并继承最近的毛色和设置。两边原始存档均保留，之后不会用旧 Unity 镜像覆盖网页的新进度。
浏览器可能要求首次点击才能播放声音，主菜单和暂停页可静音。
游戏区域拦截长按选字、图片拖动和缩放手势；主菜单仍可横向滑动。切到后台会暂停并清理按住状态。
跳跃、滑铲、冲撞、受击使用六段猫叫录音按动作分组轮换，避免连续重复；受击声优先，不排队播放过时动作。

## 修改与构建

1. 修改根目录的 `app.js`、各玩法模块、CSS 及美术音频资源。
2. `python3 -m http.server 8864 --bind 127.0.0.1` 本地试玩。
3. `npm test` 执行玩法、输入、碰撞、相机、音频与存档迁移测试。
4. 提交并推送 main，GitHub Pages 从根目录自动发布，网址不变。

`build-info.json` 记录当前引擎。Unity 工程与旧构建仅作备份；打包脚本已有显式保护，避免误覆盖当前网页。

## 目录

- 根目录 `index.html`、`app.js`、`assets/`、`audio/`：当前公开试玩源码与资源。
- `unity/`、`Build/`：保留的 Unity 工程与旧网页构建，不参与当前运行。
- `legacy-web/`：迁移前的只读参考备份，后续改根目录。
- `tools/package-unity.mjs`：受保护的旧 Unity 打包脚本。
